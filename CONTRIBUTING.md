# Contributing

Contributions to NS2-Nam for macOS are welcome.

## Ways to Contribute

- Report bugs through GitHub Issues
- Suggest improvements or features
- Improve documentation
- Submit fixes or improvements through pull requests
- Test the project on different macOS and Apple Silicon configurations

## Pull Requests

1. Fork the repository.
2. Create a new branch for your changes.
3. Test your changes locally.
4. Commit your changes with a clear message.
5. Open a pull request with a brief description of what you changed.

For significant changes, please open a Discussion first so the approach can be discussed.

## Reporting Bugs

When reporting a bug, include:

- macOS version
- Apple Silicon chip (M1, M2, M3, M4, etc.)
- Docker Desktop version
- XQuartz version
- Relevant terminal output
- Steps to reproduce the problem

Thank you for contributing.
