8 ANSWERS
01What do I need before installing?+

Install Docker Desktop and XQuartz, and make sure Docker Desktop is running. The installer needs an internet connection to download the project files and build the Docker image.

Installation requirements ↗
02How do I start NS-2?+

Run ns2 in Terminal. It opens an interactive shell in the Docker environment. Your ~/NS2Nam/simulations folder is available inside the container at /simulations.

Launch guide ↗
03How do I run a simulation?+

From the NS2-Nam shell, run the Tcl script with ns:

NS2-NAM SHELL
ns send_receive.tcl

The sample creates send_receive.nam and opens it in NAM when the simulation finishes. Open it manually with nam send_receive.nam.

04Why does NAM fail to open?+

Make sure XQuartz is installed and running. The installer enables local X11 connections with xhost +localhost. The launcher requires ~/.Xauthority and mounts it read-only into the container.

Troubleshoot NAM display ↗
05Does it work on Apple Silicon?+

Yes. Docker runs the NS-2/NAM image as linux/amd64 on Apple Silicon.

Compatibility notes ↗
06Where should I put my Tcl files?+

Put them in ~/NS2Nam/simulations on macOS. They appear in /simulations inside the ns2 environment and remain on your Mac between sessions.

07How does X11 access work?+

The installer runs xhost +localhost to allow local clients, including Docker, to connect to XQuartz. The launcher mounts ~/.Xauthority read-only. The uninstaller runs xhost -localhost to revoke the grant.

08How do I uninstall NS2-Nam?+

Download and run the uninstaller from the README. It requires confirmation, preserves your simulations, and does not remove other Docker images, containers, volumes, or Docker Desktop data.
