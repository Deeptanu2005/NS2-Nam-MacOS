01 / RUNTIME

Docker won’t start

The installer and ns2 launcher require Docker Desktop to be installed and running.

  • Open Docker Desktop and wait for it to finish starting.
  • Run docker info in Terminal to check that the Docker daemon responds.
  • If the image is missing, rerun the installer to build the NS2-Nam Docker image.
02 / AUTHORITY FILE

“XQuartz Xauthority file not found”

The launcher expects ~/.Xauthority and mounts it read-only into the container.

  • Open XQuartz and make sure it has finished starting.
  • Check whether ~/.Xauthority exists in your Mac home folder.
  • Start a fresh ns2 session after XQuartz initializes.

See the compatibility notes for all display requirements.

03 / GRAPHICS

NAM does not open

NAM’s graphical window is displayed through XQuartz. The installer enables local X11 connections with xhost +localhost.

  • Confirm XQuartz is installed and running.
  • Close and reopen XQuartz, then start a new ns2 session.
  • The launcher finds the Mac IPv4 address on en0, then en1. Another network interface may need a launcher adjustment.

04 / SIMULATION

The Tcl command cannot find my file

Simulation scripts should be saved in ~/NS2Nam/simulations on macOS. The folder appears as /simulations inside the container.

NS2-NAM SHELL
ns send_receive.tcl

Run the command from the container’s /simulations working directory. The included example writes send_receive.nam.

05 / INSTALLATION

Need to start over?

The uninstaller asks for confirmation, preserves your simulation scripts, and offers a separate confirmation before removing Docker resources.
