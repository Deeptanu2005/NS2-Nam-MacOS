How compatibility works
NS-2 and NAM run in Docker Desktop’s emulated linux/amd64 environment; XQuartz displays NAM. This is a target for Apple silicon Macs with M1 and later chips, not individual certification of every configuration or a native ARM build. Check Docker Desktop’s current macOS requirements.
